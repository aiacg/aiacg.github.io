スタジオ山ロマン (Cccpo)

(同人CG集) [スタジオ山ロマン (cccpo)] 種付家の一族～過疎村の淫習で俺の子種で孕みたい女たちは喜んで股を開く～

本页为收录内容 点击下方按钮跳转查看内容详情 前往查看详情 简介 ▼あらすじ 大学の夏の長期休暇で何かバイトをしようと探していたところ、 両親から高額報酬の住み込みのバイトがあると教えられ、 遠縁の住む村へと行くことにした草野桂太（くさのけいた）。 その遠縁というのはいわゆる本家にあたる親戚で、 雇い主である本家当主代理の椎名（しいな）が住む屋敷に到着すると、 そこには椎名以外に三人の女子校生が待ち受けていた。 椎名の一人娘である蓮花（れんか）。 そして分家の姉妹、姉の藍（あい）と妹の茜（あかね）。 そして仕事の内容は自分たちを孕ませることだと椎名から説明をされる。 彼女たち、種付（たねつ）家の一族では代々当主は本家の男性が継ぐと決められていた。 だが、唯一本家の男性であった椎名の旦那が亡くなってしまい、 当主となれる者がいなくなってしまった。 本家の男性がいなくなった時、あることをする風習があった。 それは血族から若く精力が強い男性と、 本家の血を濃く受け継ぐ子を産める身体の女性を集めて、 誰かが孕むまで子作りを行うという淫習。 その該当する男性が桂太だった。 そして子作りをする相手は椎名、蓮花、藍、茜の四人。 彼女たちを孕ませるため、子作りをしていく。 机翻简介： 我想在大学的暑假做点兼职， 父母告诉我有一份高额的包吃包住的打工， 草野桂太决定前往远亲居住的村庄。 那个远亲就是所谓的本家亲戚， 来到雇主本家户主代理椎名所住的宅邸。 除了椎名，还有三个女高中生在那里等着。 是椎名的独生女莲花。 还有旁支的姐妹，姐姐蓝和妹妹茜。 椎名解释说，工作的内容就是让她们怀孕。 她们，种付家的一族，世世代代都决定由本家的男性来当主。 但是，唯一的本家男人椎名的丈夫去世了。 没有人能当家主了。 有个习俗，当本家的男性去世时，会做一件事。 从血亲到年轻精力旺盛的男性， 召集那些能生下浓浓的本家血统的孩子的女性， 这个男人就是桂太。 而要生孩子的对象是椎名、莲花、蓝、茜四个人。 为了让她们怀孕，去生孩子。 DMM:点我 有爱自取
