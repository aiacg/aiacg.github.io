本页为收录内容 点击下方按钮跳转查看内容详情 前往查看详情 简介 网站里已经好久没有VR作品上传了，于是我上DLsite找到了这部作品花了一百大洋买来试了试。感觉还行。不过是生肉、有码。 最初我用pico4在pico互联里用steamVR启动这个游戏，发现手柄没有用。后面发现是要先在电脑上启动exe程序，在窗口里用鼠标点击“用VR启动”，然后在头显里就能用手柄动了。 下载了文件你会发现有两个文件夹，一个是“forward”文件夹，里面的游戏是关闭了FSD和光线追踪的，相对来说不是那么吃配置，另一个“deferred”文件夹里的非常吃配置，我的电脑反正带不动，作者说是起码要4070ti。大家看自己需求。游戏里设定也可以调画质，但我是日语苦手，看不太懂怎么调。 然后再（场面1,2）里有一关是要用手柄抓金鱼，我开始怎么调视角都没用，手柄怎么都够不到金鱼，后面发现要同时按住同个手柄上的两个扳机键才能把头低下去。 场面四是趁着巫女睡着逃出神社，逃走失败触发上面两个场景。逃走成功触发下面两个场景。逃走需要先点燃三盏灯，点灯过程中会突然背景音一变，然后突然出现开始追你。一般追个几秒就消失了，这时回去重新点灯就好。从左往右或者从右往左按顺序点就行。一旦被追到就要从头开始。逃出大殿后会在大殿门口堵你，这时回头跑带着她绕一圈再跑出去就行。 sex场景里用右手柄按Y可以呼出菜单，但都是生肉，只能靠猜。在某些阶段写着“射精可能”时按下扳机键就可以设了。 当然也可以不用VR玩，直接打开exe不点vr开始就行。总的来说这部游戏的ASMR要素比较多（最后一个场景是在你耳边陪你睡觉的ASMR）。逃走的场景我逃了半个小时，有一点恐怖要素，我后背和大腿上汗都下来了。 购买网址及凭证 ■ 注意事项 ■ 关于同捆版本 本作品包含 Forward版 和 Deferred版 两种版本。 【Forward版（DirectX 11）】 这是侧重VR游玩、稳定性和帧率的版本。对网格和光照进行了一定调整，相比Deferred版负载更低。 进行VR游玩时，原则上推荐使用此Forward版。 【Deferred版（DirectX 12）】 这是支持TSR和光线追踪的高画质版本。适合在PC模式下追求高画质的玩家。 虽然也可以启动VR模式，但需要非常高的PC配置。 ※Deferred版推荐使用支持DirectX 12 Ultimate的GPU。 在不支持的GPU上可能无法启动或运行不稳定，此时请使用Forward版。 — ■ 关于VR游玩 VR模式对PC负载较高，因此推荐使用Forward版。 已确认的运行环境： Meta Quest 2 / Meta Quest 3S / Meta Quest 3 + Virtual Desktop ...
