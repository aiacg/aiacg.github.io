游戏作者:Raay 一些内容可见： 我懒得打了。 游戏已经停止更新了，在24-3-8，最终版本0.4，这里只是看站里没有补一个新的。 题材和内容我感觉是很好的，不过有点可惜。作者自己说他不太满意，没继续更新。 算是纪念这个游戏（?） 其他的可以看游戏页和Patreon，作者在那儿有个新的游戏。 作者原话（机翻） ——————————————公告——————————————— 嗨，我是 Raay。 我有一个把事情搞长的坏习惯。所以简而言之：

  1. 魅魔游戏将不再更新……和 阿拉伯数字。我的新项目 Project Hypnosis 将在这个新的 Patreon 页面上更新： 我会解释一切。 ————————————————————————————————– – 我最近的状态： 众所周知，这个项目已经停工一年多了。与此同时，我忙于谋生并为我的新游戏起草想法。但最终我意识到：独自制作一款拥有如此大量内容的游戏可能需要数年时间。这项业务能否在让你们，或者老实说，我自己等待这么长时间的情况下维持下去？更不用说要拿出一个真正的成品了。 我开始寻找另一种方式，最终，我与一家工作室建立了合作伙伴关系。只需少量投资，我现在可以再次专注于这个职业一段时间，并尝试将这个游戏变为现实。 – 魅魔游戏： 需要明确的是，Succubus Game 的开发已关闭。而 v0.4 是该项目的最后一次更新。 2 个主要原因。首先，如前所述，这种发展是不可持续的。如果我一直努力到现在，它可能会像 v0.7 或 v0.8 一样？甚至不到游戏的一半才能完成。第二个原因来了，我很高兴继续开发一个足够好的项目。但作为我第一次尝试游戏开发，Succubus Game 在质量方面开始让我不满意。 向所有喜欢 Succubus Game 的人道歉。我相信我从它的开发中学到了宝贵的一课，这将有助于这个新项目。

– 催眠计划： Project Hypnosis 是一款全新的催眠主题成人游戏。 这是我游戏开发生涯的第二次尝试，这次我的目标是发布它的完整版本。 第一个演示目前计划在 2024 年 7 月之前免费公开首次亮相。然后，Patreon 将提供最新版本的抢先体验。游戏的完整版将在完成后发售。与此同时，我会继续在新的 Patreon 页面上更新进度。 如果你一直在关注我的 Patreon，你们中的一些人可能已经注意到这次这是一款单色（黑白）艺术风格的游戏！我知道它在艺术和游戏系统上与我们之前的魅魔游戏有很大不同。游戏的细节将在演示中展示，所以当时试一试，让我知道你们的想法！ – 成为 Patron 有什么好处？ 首先，我有责任非常清楚地说明：目前付费会员和免费会员之间没有区别。 在第一个演示发布之前，Patreon 上的每篇帖子都是公开可见的。 现在只有 1 个会员等级，即 Early Supporter，它仅在第一个演示发布后一个月可用。之后，此层级将设置为 limited （对新用户不可用）。 早期支持者可以享受与未来新基本层相同的好处（价格更高），包括访问最新游戏版本等功能，价格与现在相同。 您还不喜欢支持还没有什么可玩的项目吗？以免费会员身份加入并等待演示！（Patreon 第 -> 页右上角 “…”按钮）

– 为什么这个项目需要支持？ 作为创作者，我有无限的想法和想法可以投入到游戏中。但实际上，我们总是需要用有限的资源管理好我们的计划。您的每一位支持都会让我们知道有人喜欢我们正在做的事情，我们会一直这样做，直到它成为我想呈现给您的最终形式。 换句话说，更多的订阅会员将解锁更多内容，以便在我们的开发计划中实施。如果您喜欢并希望看到这个项目变得越来越好，我们将非常感谢您加入新的社区！ 感谢您对 Succubus Game 的所有喜爱！我们的新游戏见！！ ————————————————公告—————————————————– 大家好~ 我是Raay! 每次我都会把东西讲得太长，所以先在此划出本公告的重点：

  1. Succubus Game 将不再更新… 但是！
  2. 新作 Project Hypnosis 将在以下新专页上更新： 以下是详细的说明~ ————————————————————————————————– -地位： 有在关注本作的各位也会知道，本专页已有一年多没有更新新游戏内容。 在这段时间我只有少量空余时间去做游戏上的东西。 最后我不得不向现实妥协：独自制作如此体量的游戏实在需要太多时间。 机缘巧合下我找到了一家工作室进行合作，以一笔小投资暂时让我可以再次专注在游戏开发一段时间，尝试将本作实现。

– Succubus Game 的狀況？ Succubus Game 的开发已经停止 主要原因有两个，首先是其开发日程实在过于漫长，此外作为首款作品我也开始对其品质感到不满意 很抱歉所有喜欢 Succubus Game 的朋友们，我会将开发过程所得的经验投入到新作中！

– 催眠计划： 《Project Hypnosis》是一款催眠题材的 H-Game，本人生涯中的第二款作品，目标是能开发出完整版本 目前首个 demo 预计于 2024 年 7 月之前免费发布，未来的版本将可在 Patreon 上抢先体验。 游戏完整版本将于完成后贩售。 在此之前，我们会一直在 Patreon 上持续更新各种情报和进度！ 有追踪的各位可能已注意到，与前作十分不同，本作是一款黑白风格的游戏！ 各位在 Demo 版本发布后请务必尝试并告诉我您的感想！

– 成为发起人的奬励？ 注意： 目前成为付费会员和免费会员可获取的内容没有分别。 在首个 demo 发布前，新 Patreon 上的每个帖子都是公开可见的 目前只有一个会员等级可选（早期支持者），并且在首个 demo 发布一个月后此会员等级将会被锁定（新用户将无法订阅此等级） 早期支持者可一直以相同月费获取之后新增的基本会员等级的奖励，如抢先体验最新的游戏内容等 若目前仍没有赞助的打算，也请务必成为免费会员以取得首个 demo 发布的通知！ （Patreon 专页-> 右上角 “…” 按键）

– 为什么要支持我們？ 包括美术、动画、编程和故事等大部分的游戏内容会继续由我一人负责，而我的合作伙伴提供了一些财务上的支持以支撑基本开发日程。 但我们仍依頼各位的支持以决定完整版本中的内容量 作为创作者，我有很多很多有趣的想法期望能够投入本作中实现，但现实中必需规划有限的资源来进行开发。 各位的支持能令我们对本作的开发更有信心，并能在完整版本中实装更多不同的游戏内容

再次感谢大家对本作的支持！ 希望能在新作中与各位再见！
